# Exercícios de Programação Orientada a Objetos em Java

Repositório dedicado à prática e ao desenvolvimento de conhecimentos em **Programação Orientada a Objetos (POO) com Java**.

O objetivo é aplicar conceitos fundamentais da linguagem por meio de exercícios práticos, desenvolvendo o raciocínio lógico, a organização do código e a capacidade de resolver problemas utilizando os princípios da orientação a objetos sem o uso de IAs.

## Conteúdos praticados

- Classes e objetos;
- Atributos e métodos;
- Construtores;
- Encapsulamento;
- Getters e Setters;
- Modificadores de acesso;
- Sobrecarga de métodos;
- Listas e arrays de objetos;
- Manipulação de dados e entrada pelo teclado;
- Métodos `toString()`.
- Enumeração
- Composição
- Matrizes

## Tecnologias

- **Java** — linguagem utilizada no desenvolvimento dos exercícios.
- **Git** — versionamento dos códigos.

## Objetivo

Este repositório faz parte da minha jornada de aprendizado em Java, reunindo exercícios e implementações desenvolvidos para consolidar os fundamentos da Programação Orientada a Objetos.

Os códigos poderão receber melhorias e refatorações conforme minha evolução nos estudos.
